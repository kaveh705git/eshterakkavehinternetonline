# 🌐 مدیریت مشترکین خدمات اینترنتی آنلاین کاوه

سیستم مدیریت اشتراک، روزشمار و سهمیه خدمات برای مشترکین.

## ✨ امکانات

- مدیریت مشترکین (افزودن / حذف)
- سه پلن اشتراک: برنزی، نقره‌ای، طلایی
- روزشمار خودکار (کاهش روزهای باقیمانده)
- کسر خودکار سهمیه خدمات
- کد مخصوص یکتا برای هر مشترک
- کد تخفیف ویژه هر مشترک
- پنل ورود ادمین
- خروجی Excel/CSV
- یادآوری انقضای اشتراک
- چاپ کارت مشترک

## 🚀 نحوه استفاده

فایل `index.html` را در مرورگر باز کنید.

- نام کاربری پیش‌فرض: `admin`
- رمز عبور پیش‌فرض: `kaveh123`

> ⚠️ برای تغییر رمز، فایل `js/app.js` را باز کرده و مقادیر `ADMIN_USER` و `ADMIN_PASS` را تغییر دهید.

## 🛠️ تکنولوژی
